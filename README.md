# Evie's Snake Game (Tkinter) 🐍
####  Program created by Evie Durdin
This is a simple version of the classic Snake game that I built using Python and Tkinter. 
The snake moves around, eats food, and gets longer. If you crash into yourself, it’s game over. 
You can pause the game, and the snake wraps around the edges of the screen instead of hitting a wall.

### Features
- Snake grows when it eats food
- Score goes up each time you eat
- Pause and resume with the **spacebar**
- Wrap-around screen 
- Basic game over screen when you crash into yourself

### How to Play 🕹️
- Use the arrow keys to move:
  - '↑' Up
  - '↓' Down
  - '←' Left
  - '→' Right
- Press 'Spacebar' to pause or unpause
- Eat the yellow food to grow and increase your score
- The snake wraps around edges, but don’t run into yourself or it’s game over
